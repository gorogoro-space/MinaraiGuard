# MinaraiGuard

新規プレイヤーの見習い期間とスポーン地点の保護で、他の人の建築と景観を守る Paper 用プラグインです。

新しく来たプレイヤーの自由はできるだけ残しながら、昔からある建築やサーバーの景観を壊されないようにすることを目的にしています。

## 主な機能

### 見習い期間

初めて参加したプレイヤーは、プレイ時間が一定時間(初期値 5 時間)に達するまで「見習い」として扱われます。見習い期間中も、自分で置いたブロックや、土・石などの地形ブロックは自由に掘れます。自分で植えた苗木から育った木も伐採できます。一方で、他の人の建築や、原木・葉・鉱石などの景観・資源ブロックは壊せません。

資源は資源ワールドで制限なく集められるので、見習いには `/shigen` で資源ゲートの前へ移動できることを案内します。プレイ時間が規定に達すると自動で昇格し、タイトル表示と効果音で知らせます。

### スポーン地点の保護

指定した範囲(高さは問わず X・Z で指定)では、全員に対してブロックの破壊・設置・バケツの使用を禁止します。ただし看板は、昇格後のプレイヤーなら設置・破壊できるので、スポーンの掲示板に看板を貼れます。ドア・ボタン・レバー・チェスト・看板などの操作は自由にできるので、スポーンのテレポート看板や共用チェストもそのまま使えます。

リピーターやコンパレーターなど、右クリックで状態が変わるブロックの操作や、斧での樹皮剥ぎなど道具によるブロックの変化も防ぎます。爆発、ピストン、液体の流れ込み、エンダーマン、範囲外で育った木の侵入など、プレイヤー以外による変化からも保護します。トロッコは普通のトロッコだけ置けます。

### わかりやすい案内

制限にかかったときは、アクションバーに理由と昇格までの残り時間を短く表示します。チャットでの詳しい案内(クリックで実行できる `/shigen` と `/minarai` の紹介)は、ログイン中に初めて制限にかかったときの 1 回だけ表示し、画面が埋まらないようにしています。

短時間に別々のブロックを次々と壊そうとするなど、意図的な破壊と判断できる場合は「警戒モード」に入り、案内を一定間隔で繰り返し表示します。必要に応じて管理者への通知もできます。

## 見習いと昇格後の違い

見習いに追加でかかる制限は、スポーン外でのブロックの破壊だけです。ブロックの設置や右クリックの操作は、スポーン外なら見習いも自由にできます。スポーン保護は見習いにも昇格後のプレイヤーにも同じようにかかります。

### スポーン外(`apprentice.worlds` のワールド)

| 操作 | 見習い | 昇格後 |
|---|---|---|
| 自分が置いたブロックを壊す | ○ | ○ |
| 自分が植えた苗木から育った木を壊す | ○ | ○ |
| 地形ブロック(土・草・砂・砂利・石・深層岩・雪など、`terrain-blocks`)を壊す | ○(他の人の建築に使われていても壊せる) | ○ |
| 景観・資源ブロック(原木・葉・苗木・花・鉱石・カボチャ・サトウキビ・竹など、`resource-blocks`)を壊す | ×(`/shigen` を案内) | ○ |
| 上記以外のブロック(他の人の建築など)を壊す | × | ○ |
| ブロックの設置・バケツ・右クリックの操作 | ○ | ○ |

資源ワールドなど、`apprentice.worlds` に含まれないワールドでは、見習いにも制限はありません。

### スポーン地点(`spawn-protection` で指定した範囲)

| 操作 | 見習い | 昇格後 |
|---|---|---|
| ブロックの破壊・設置(範囲外からはみ出すベッドやドアを含む) | × | × |
| 看板の設置・破壊(`member-blocks`。他の人の看板は LWC などで保護する前提) | × | ○ |
| バケツで汲む・撒く | × | × |
| リピーター・コンパレーター・植木鉢・ケーキ・コンポスターなど(`deny-blocks`)の右クリック | × | × |
| 道具によるブロックの変化(樹皮剥ぎ・道づくりなど)、骨粉 | × | × |
| 畑や亀の卵を踏み荒らす | × | × |
| 普通のトロッコ以外(チェスト付きなど)の設置 | × | × |
| 書見台の本を取り出す | × | × |
| ドア・ボタン・レバー・感圧板・チェスト・看板の操作、GSit で座る、書見台の本を読む、普通のトロッコの設置 | ○ | ○ |

`minarai.bypass` を持つプレイヤー(初期設定では OP)は、スポーン保護を受けません。`minarai.exempt` を持つプレイヤー(初期設定では OP)は、プレイ時間にかかわらず見習いとして扱われません。

## 動作環境

Paper 1.21.11 と Java 21 で動作するように作られています。

## 導入

1. [Releases](../../releases) から jar をダウンロードするか、下記の手順でビルドします。
2. サーバーの `plugins` フォルダに jar を入れて起動します。
3. 生成された `plugins/MinaraiGuard/config.yml` で、スポーン範囲を自分のサーバーに合わせて設定し、`/minarai reload` を実行します。
4. 管理者が資源ゲートの前に立ち、ゲートの方を向いて `/minarai setgate` を実行します。その場所と向きが `/shigen` の移動先として保存されます。

スポーン範囲と資源ゲートの座標は必須設定です(資源ゲートの高さと向きは省略でき、省略時は地表に移動します)。config.yml からこれらの項目が欠けていると、起動時にエラーを出してプラグインを無効化します。

## ビルド

JDK 21 と Gradle 8 以降が必要です。

```
gradle build
```

`build/libs/MinaraiGuard-<バージョン>.jar` が生成されます。

## 開発(IntelliJ IDEA で Claude Code を使う)

このリポジトリには、AI コーディングツール [Claude Code](https://docs.claude.com/ja/docs/claude-code/overview) 向けの作業ルールを書いた `CLAUDE.md` があります。IntelliJ IDEA で使う手順は次のとおりです。

1. Claude の有料プラン(Pro / Max)か、Anthropic API のアカウントを用意します。
2. Windows では、先に [Git for Windows](https://git-scm.com/downloads/win) をインストールします。
3. Claude Code 本体をインストールします。Windows では PowerShell で次を実行します。
   ```
   irm https://claude.ai/install.ps1 | iex
   ```
4. IntelliJ IDEA の「設定 → プラグイン → Marketplace」で「Claude Code」を検索してインストールし、IDE を再起動します。検索結果には Anthropic 以外が作った似た名前のプラグインも表示されます。プラグイン名の下に書かれた提供元が「Anthropic」になっているものを選んでください。
5. プロジェクトを開いて、ターミナルで `claude` を実行します(`Ctrl+Esc` でも起動できます)。初回はブラウザでログインします。

起動すると `CLAUDE.md` が自動で読み込まれ、このプロジェクトの設計方針に沿って作業します。

## コマンド

| コマンド | 説明 | 権限 |
|---|---|---|
| `/minarai` | 見習い期間の残り時間を表示 | なし |
| `/shigen` | 資源ゲートの前へ移動(資源ワールドのリセット日も表示) | `minarai.shigen` |
| `/minarai setgate` | 現在地と向きを `/shigen` の移動先に設定 | `minarai.admin` |
| `/minarai reload` | 設定を再読み込み | `minarai.admin` |

## 権限

| 権限 | 説明 | 既定 |
|---|---|---|
| `minarai.bypass` | スポーン保護を無視してブロックを変更できる | OP |
| `minarai.exempt` | 見習いとして扱われない | OP |
| `minarai.notify` | 警戒モードに入ったプレイヤーの通知を受け取る | OP |
| `minarai.shigen` | `/shigen` で資源ゲートへ移動できる(権限管理プラグインで false にした場合のみ使えなくなる) | 全員 |
| `minarai.admin` | `/minarai reload` と `/minarai setgate` を実行できる | OP |

## 設定

設定はすべて `config.yml` にあり、各項目にコメントで説明を付けています。主な項目は次のとおりです。

| 項目 | 内容 |
|---|---|
| `spawn-protection` | スポーン保護の範囲(必須) |
| `resource-gate` | `/shigen` の移動先(必須)。`/minarai setgate` で設定できます |
| `resource-reset.day-of-month` | 資源ワールドのリセット日(毎月何日か)。0 で案内しない |
| `resource-reset.time` | リセットされる時刻(例: `"05:20"`) |
| `resource-reset.time-zone` | 時刻の基準となるタイムゾーン(例: `Asia/Tokyo`)。空欄ならサーバーの設定 |
| `resource-reset.warn-days` | リセットまでの残りがこの日数を切ると、案内を目立つ色で表示する |
| `apprentice.hours` | 見習い期間(プレイ時間、単位は時間) |
| `apprentice.worlds` | 見習いのルールを適用するワールド。資源ワールドは入れません |
| `apprentice.terrain-blocks` | 見習いでも掘れる地形ブロック |
| `apprentice.resource-blocks` | `/shigen` を案内する景観・資源ブロック |
| `spawn-interaction.deny-blocks` | スポーン内で右クリック操作を禁止するブロック |
| `spawn-interaction.member-blocks` | 昇格後のプレイヤーがスポーン内で設置・破壊できるブロック(初期値は看板すべて) |
| `spawn-interaction.allowed-minecarts` | スポーン内に置けるトロッコ |
| `warning` | 警戒モードの判定と表示間隔、管理者通知。警戒モードは常に有効で、管理者通知(`notify-admins`)は初期設定ではオフです |
| `messages` | すべてのメッセージ(MiniMessage 形式) |

ブロックは `OAK_LOG` のような名前か、`"#logs"` のようなタグで指定できます。メッセージを空文字 `""` にすると、そのメッセージは表示されなくなります。

## 表示されるメッセージ

| 場所 | 条件 | 対象 | アクションバー | チャット案内 |
|---|---|---|---|---|
| スポーン外 | 他の人の建築などを壊そうとした | 見習い | 見習い期間中のため、このブロックは壊せません | /minarai 案内 |
| スポーン外 | 景観・資源ブロックを壊そうとした | 見習い | 見習い期間中はこのブロックを採れません | /shigen 案内 + /minarai 案内 |
| スポーン | ブロックを壊す・置く・バケツを使う | 全員 | スポーン地点のブロックは変更できません | 見習いのみ /shigen 案内 + /minarai 案内 |
| スポーン | 看板(`member-blocks`)を置こうとした | 見習い | 見習い期間中はスポーン地点に看板を設置できません | /minarai 案内 |
| スポーン | 状態が変わるブロックを操作した | 全員 | スポーン地点ではこのブロックを操作できません | なし |
| スポーン | 道具でブロックを変化させようとした | 全員 | スポーン地点ではこの道具を使えません | なし |
| スポーン | 普通のトロッコ以外を置こうとした | 全員 | スポーン地点では(種類)は置けません | なし |

チャット案内は、ログイン中に初めて制限にかかったときの 1 回だけ表示されます(警戒モード中は一定間隔で繰り返し)。このほか、初回ログイン時の歓迎メッセージ、昇格時のタイトル表示があります。`/shigen` で移動したときには、「資源ワールドは毎月1日5:20にリセットされます(あと3日)」のように、リセットまでの残り時間も表示します。残りが1日を切ると「あと○時間○分」の表示になり、残りが少ないとき(初期値は 3 日未満)は赤色で目立たせます。

## データの保存

見習いが置いたブロックの記録は `plugins/MinaraiGuard/placements.db`(SQLite)に保存されます。プラグインフォルダ以外には何も書き込みません。SQLite のドライバは Paper に同梱されているため、追加のライブラリは不要です。

データベースの読み書きはすべて別スレッドで行い、書き込みは 1 秒ごとにまとめて反映するので、TPS への影響はほとんどありません。見習いが昇格すると、その人の記録は削除されます。記録はプラグイン導入後に見習いが置いたブロックだけが対象です。

## 他のプラグインとの併用

チェストや看板の保護(LWC など)、延焼の防止、TNT による破壊の防止は、それぞれ専用のプラグインに任せる前提で、このプラグインでは扱いません。額縁や防具立ても対象外です。

GSit など、階段やハーフブロックを右クリックして座るプラグインは、スポーン内でもそのまま使えます。Multiverse-Core などで作ったワールドも、ワールド名で指定できます。

## 注意事項

`apprentice.terrain-blocks` に含まれるブロック(土・石など)で作られた既存の建築は、スポーン外であれば見習いでも壊せます。気になるブロックはリストから外してください。

スポーン内では、村人の畑仕事や羊が草を食べるなど、エンティティによるブロックの変化もすべて止まります。

server.properties の `spawn-protection`(バニラのスポーン保護)が有効で、その範囲がスポーン施設に重なっていると、OP 以外のプレイヤーはドアやチェスト、看板などを操作できません。スポーン内の操作を許可したい場合は `0` にしてください。

ログイン直後、記録の読み込みが終わるまでのごく短い間(通常は数ミリ秒)は、自分で置いたブロックでも壊せないと判定されることがあります。
